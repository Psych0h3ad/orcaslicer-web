ORCASLICER WEB · CUBBYSLICER

iPadでも、モデルから
G-codeまで。

OrcaSlicerのスライスエンジンを、この端末のブラウザで動かします。アカウントやスライス用サーバーは不要です。CubbySlicerをもとにした非公式Web版です。

  1. モデルを開く

    「モデルを開く · Import」を押し、iPadの「ファイル」からSTL・OBJ・STEP・3MFを選びます。以前保存した3MFプロジェクトはFile → Openから開けます。

  2. プリンターと材料を選ぶ

    左上のサイドバーボタンを押して設定を開きます。Printerで実機とノズル径、Filamentで材料、Processで印刷条件を選びます。初回のセットアップでも選択できます。

  3. スライスして確認

    右上の「Slice plate」を押します。完了したらPreviewで印刷経路を確認してください。レイヤースライダーで内部やサポートも確認できます。

  4. G-codeを保存

    「Export G-code」からダウンロードします。Safariのダウンロード一覧と「ファイル」から取得できます。編集可能な状態はFile → Save projectで3MFに保存します。

タッチ操作

1本指で視点を回転、2本指でズーム・移動できます。モデルをタップすると選択できます。プリンター設定やオブジェクト一覧は、左上のサイドバーボタンから開きます。Safariの共有メニューから「ホーム画面に追加」すると、次回から開きやすくなります。

対応範囲とトラブルシュート

iPadでの動作とモデルの大きさ

最新のiPadOSとSafariを推奨します。WebAssemblyとWebGLが必要です。この配布版の実エンジンスライスは検証していますが、iPad実機での動作はまだ確認していません。まず小さいモデルで試してください。大きいモデルでタブが再読込される場合は、モデルを軽量化するかPCで処理してください。

スライスが始まらない・設定が出ない

初回はエンジンとプロファイルの取得にネット接続が必要です。回線を確認してページを再読込してください。モデルを配置し、対応するプリンター・材料・プロセスを選んでからSlice plateを押してください。エラーが出た場合は表示された設定項目を確認してください。

マルチスレッドで使うには

Chrome・Edgeなどでは起動時に有効化を試みます。初回は編集画面を開く前に一度だけ再読み込みする場合があります。Preferences → Slicing → Slicing threadsで自動またはスレッド数を選択できます。スライス後の「2T」などの表示が実際に使用したスレッド数です。

Safari・iPadではブラウザ側の既知の問題があるため、既定はシングルスレッドです。「実験的MTを試す・再読み込み」から試せます。切替時はプロジェクトのブラウザ内保存を完了してから再読み込みします。保存できない場合は切替を中止します。

不調になった場合はシングルスレッドで開くで復旧できます。MTの起動・実行に失敗した場合もSTへ退避します。速度はモデルと端末に依存し、iPad実機での検証は未実施です。

PC版との違い

OrcaSlicer 2.5.0のST・MT WASMエンジンを使用します。デスクトップ版のすべての機能・プロジェクトとの完全互換は保証していません。この配布版ではクラウド保存、AI/MCP接続、Pythonプラグイン、preFlightエンジンを提供していません。Python処理が必要なプロジェクトは、理由を表示してスライスを停止します。

プリンターへ送信するには

まずG-codeを保存し、お使いのプリンターに適した方法で渡してください。直接送信はプリンター側のCORS・HTTPS対応などに左右されます。G-codeの生成とプレビューはプリンターへの接続なしで使えます。

ファイルと保存について

モデルはブラウザ内で処理し、外部のスライスサーバーへ送信しません。ページとエンジンはGitHub Pagesから読み込みます。自動保存はこのブラウザ内の補助機能です。大切なプロジェクトは3MFファイルとして保存してください。オフライン動作は保証していません。
